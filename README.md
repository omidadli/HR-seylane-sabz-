# سامانه مدیریت منابع انسانی کارا (Kara Enterprise HRMS)
### سامانه جامع و بومی منابع انسانی ویژه بازار ایران با دستیار هوشمند استخدام Gemini، تقویم جلالی و تطابق کامل با قانون کار

---

## ۱. معرفی کلی سامانه
«کارا» یک سامانه سازمانی یکپارچه برای مدیریت چرخه عمر سرمایه‌های انسانی در شرکت‌ها و هولدینگ‌های ایرانی است. این سامانه با درک دقیق مقتضیات بومی بازار کار ایران طراحی شده است:
- **پشتیبانی سراسری از زبان فارسی و چینش RTL** با تایپ‌فیس اختصاصی و بهینه‌شده **وزیرمتن (Vazirmatn)**
- **تقویم و تاریخ‌نگار شمسی (جلالی)** با مبدل دقیق تقویم، تقویم روزهای کاری و کامپوننت انتخاب‌گر اختصاصی تاریخ
- **قانون کار و تامین اجتماعی جمهوری اسلامی ایران**: محاسبات حقوق پایه، بن خواربار، حق مسکن، حق اولاد (ماده ۸۶)، ۷٪ بیمه سهم کارگر، پله‌های مالیات بر حقوق، ذخیره سنوات و عیدی پایان سال، و مدیریت مرخصی سالانه (۲۶ روز کاری مصوب قانون کار).
- **دستیار هوشمند ارزیابی و استخدام (AI Recruiter)** مبتنی بر مدل‌های هوش مصنوعی Gemini شرکت گوگل با قابلیت **Function Calling**: استخراج معیارهای وزنی شغل، امتیازدهی ۱ تا ۱۰ به رزومه‌ها با ارجاع به شواهد متنی، مقایسه همزمان در نمودار رادار و پیش‌نویس ایمیل‌ها.

---

## ۲. ساختار پروژه و معماری ماژولار (Monorepo)
ساختار پروژه به گونه‌ای معماری شده است که تمامی مدل‌ها و قراردادهای API در لایه مشترک تعریف شوند تا در فاز بعد، اپلیکیشن موبایل **React Native / Expo (خروجی APK برای اندروید)** مستقیماً از همین بک‌اند و تایپ‌ها استفاده نماید:

```text
├── packages/
│   └── shared-types/             # تایپ‌ها و اینترفیس‌های مشترک وب، سرور و موبایل اپ
├── prisma/
│   └── schema.prisma             # اسکیما و مایگریشن پایگاه‌داده رابطه ای PostgreSQL
├── server/
│   ├── store.ts                  # لایه داده و مخزن عملیاتی با داده‌های واقعی بازار ایران
│   └── gemini.ts                 # سرویس ارتباط با هوش مصنوعی Gemini و ابزارهای Function Calling
├── src/
│   ├── components/
│   │   ├── common/               # کامپوننت‌های مشترک (JalaliDatePicker, Modal, Header, Sidebar)
│   │   ├── recruitment/          # ماژول ۱: استخدام، کانبان، بارگذاری گروهی، چت هوش مصنوعی، رادار چارت
│   │   ├── employees/            # ماژول ۲: پرونده پرسنلی و چارت سازمانی سلسله‌مراتبی
│   │   ├── attendance/           # ماژول ۳: تردد و گردش‌کار مرخصی با قانون ۲۶ روزه
│   │   ├── payroll/              # ماژول ۴: فیش حقوقی، کسورات بیمه و مالیات، حق مسکن و بن
│   │   ├── performance/          # ماژول ۵: اهداف سازمانی OKR/KPI و ارزیابی
│   │   ├── training/             # ماژول ۶: آموزش و ماتریس شایستگی‌های تیمی
│   │   ├── checklists/           # ماژول ۷: چک‌لیست ورود و خروج همکاران
│   │   └── analytics/            # ماژول ۸: داشبورد شاخص‌های کلیدی منابع انسانی
│   ├── utils/
│   │   └── jalali.ts             # موتور تبدیل تاریخ، روزهای هفته و فرمت ریال و تومان
│   ├── types/
│   │   └── index.ts              # تعریف قراردادها و انام‌های سیستمی
│   ├── App.tsx                   # داشبورد اصلی، کنترل سوییچ نقش‌ها و ناوبری ماژول‌ها
│   ├── main.tsx                  # نقطه ورود React
│   └── index.css                 # استایل‌های Tailwind و فونت وزیرمتن
├── server.ts                     # وب‌سرور Express فول‌استک با میدل‌ور Vite
├── package.json                  # اسکریپت‌ها و وابستگی‌ها
└── vite.config.ts                # پیکربندی بیلد کلاینت
```

## ۳. معرفی ماژول‌ها و سطوح دسترسی (RBAC)

سامانه از ۳ سطح دسترسی پشتیبانی می‌کند که از طریق نوار بالای برنامه به صورت زنده قابل تغییر و تست هستند:
1. **مدیر ارشد منابع انسانی (HR Director)**: دسترسی کامل به کل ماژول‌ها، تعریف مشاغل، مصاحبه‌ها، فیش حقوقی، گزارش‌های مدیریتی و تایید نهایی مرخصی‌ها.
2. **مدیر واحد / دپارتمان (Department Manager)**: ارزیابی کارجویان واحد خود، ثبت اهداف تیمی، مشاهده چارت سازمانی و مرحله ۱ تایید مرخصی‌ها.
3. **کارمند (Employee)**: مشاهده فیش حقوقی، ثبت تردد روزانه، ثبت درخواست مرخصی و مشاهده وضعیت چک‌لیست‌های ورود.

### وضعیت تفصیلی ماژول‌ها:
- **ماژول ۱: جذب و استخدام (Recruitment & Hiring) - پیاده‌سازی ۱۰۰٪ کامل**:
  - مدیریت موقعیت‌های شغلی فعال و بایگانی‌شده
  - بارگذاری گروهی بیش از ۲۰۰ رزومه به صورت هم‌زمان با نوار پیشرفت پردازش بلادرنگ
  - دستیار هوش مصنوعی Gemini با ابزارهای: استخراج معیارهای وزنی، نمره‌دهی ۱ تا ۱۰ با ارجاع نقل‌قولی، دسته‌بندی سه‌گانه، ترسیم نمودار رادار تطبیقی چندمحوره و تنظیم پیش‌نویس ایمیل
  - پایپ‌لاین کانبان ۶ مرحله‌ای (بررسی اولیه، مصاحبه تلفنی، مصاحبه حضوری، پیشنهاد همکاری، استخدام، رد)
  - تقویم مصاحبه‌های استخدامی و فرم برنامه‌ریزی با تاریخ شمسی
  - استخر استعدادها (Talent Pool) برای ذخیره کارجویان مستعد
- **ماژول‌های ۲ تا ۸ (اسکلت پایه، اسکیما و اینترفیس‌های عملیاتی)**:
  - ماژول ۲: پرونده پرسنلی، بایگانی مدارک و چارت درختی سازمان
  - ماژول ۳: تردد روزانه، سقف مرخصی ۲۶ روزه قانون کار و فرایند تایید دومرحله‌ای
  - ماژول ۴: حقوق، بن کارگری، حق مسکن، بیمه ۷٪، مالیات پله‌ای، سنوات و عیدی
  - ماژول ۵: اهداف و سنجه‌های عملکردی (OKR/KPI)
  - ماژول ۶: تقویم دوره‌های آموزشی و ماتریس شایستگی‌های تیم
  - ماژول ۷: چک‌لیست فرآیند شروع به کار (Onboarding) و خروج (Offboarding)
  - ماژول ۸: داشبورد شاخص‌های نرخ جابجایی پرسنل، هزینه استخدام و زمان جذب

## ۴. راهنمای نصب و راه‌اندازی محلی

### الزامات
- Node.js نگارش ۱۸ یا بالاتر
- کلید دسترسی `GEMINI_API_KEY` (به صورت پیش‌فرض در تنظیمات AI Studio تنظیم شده است)

### دستورات اجرا
```bash
# ۱. نصب پکیج‌ها
npm install

# ۲. اجرای سرور توسعه (پورت ۳۰۰۰)
npm run dev

# ۳. بیلد نسخه نهایی پروداکشن
npm run build
npm start
```
پس از اجرا، سامانه در آدرس `http://localhost:3000` به صورت راست‌چین و با فونت زیبای وزیرمتن در دسترس خواهد بود.
